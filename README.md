# Hoshi releases

Installers for the Hoshi desktop app (Windows). Download the latest `Hoshi_*_x64-setup.exe` from [Releases](https://github.com/Donnemesio/hoshi-releases/releases/latest).

The app checks this page for updates itself, so after the first install you never need to come back here. Every update is signed, and the app refuses any file that is not.
